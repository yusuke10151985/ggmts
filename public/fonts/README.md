# Font Files

このディレクトリには、PDFエクスポート用のフォントファイルを配置してください。

必要なフォント：
- NotoSans-Regular.ttf
- NotoSans-Bold.ttf
- NotoSansJP-Regular.ttf (or .otf)
- NotoSansThai-Regular.ttf

これらのフォントは以下からダウンロードできます：
- https://fonts.google.com/noto/specimen/Noto+Sans
- https://fonts.google.com/noto/specimen/Noto+Sans+JP
- https://fonts.google.com/noto/specimen/Noto+Sans+Thai

または、GitHub経由：
- https://github.com/google/fonts/tree/main/ofl/notosans
- https://github.com/google/fonts/tree/main/ofl/notosansjp
- https://github.com/google/fonts/tree/main/ofl/notosansthai

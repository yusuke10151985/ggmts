# Google Analytics 設定ガイド

## 🎯 測定IDの取得手順

### 1. Google Analytics アカウント作成
1. https://analytics.google.com にアクセス
2. 「測定を開始」をクリック
3. アカウント名を入力（例：GGMTS）
4. データ共有設定はデフォルトのままでOK

### 2. プロパティ設定
- **プロパティ名**: GGMTS
- **レポートのタイムゾーン**: （GMT+09:00）日本時間
- **通貨**: 日本円（JPY）

### 3. ビジネス情報
- **業種**: その他
- **ビジネスの規模**: 小（従業員数1～10名）

### 4. ビジネス目標
選択項目：
- ✅ サイトまたはアプリでのユーザー行動を調べる
- ✅ コンバージョンを最適化する

### 5. データストリーム作成
1. **プラットフォーム**: ウェブを選択
2. **ウェブサイトのURL**: https://www.ggmts.com
3. **ストリーム名**: GGMTS Production

### 6. 測定ID取得
```
測定ID: G-XXXXXXXXXX
```
この値をコピーして保存

## 🚀 Vercelへの環境変数設定

### 手順：
1. Vercelダッシュボードにログイン
2. ggmtsプロジェクトを選択
3. Settings → Environment Variables
4. 以下を追加：
   - **Key**: `NEXT_PUBLIC_GA_MEASUREMENT_ID`
   - **Value**: `G-XXXXXXXXXX`（取得した測定ID）
   - **Environment**: Production, Preview, Development すべてチェック
5. 「Save」をクリック

### デプロイ：
```bash
# 環境変数追加後、再デプロイが必要
git push origin main
# または Vercelダッシュボードで「Redeploy」
```

## 🔍 主要な測定項目

### 基本指標
- **ユーザー**: サイトを訪問した人数
- **新規ユーザー**: 初めて訪問した人数
- **セッション**: 訪問回数
- **ページビュー数**: 表示されたページ数

### エンゲージメント指標
- **平均エンゲージメント時間**: ユーザーの滞在時間
- **エンゲージメント率**: 積極的にサイトを使用した割合
- **直帰率**: 1ページだけ見て離脱した割合

### ユーザー属性
- **地域**: どこからアクセスしているか
- **デバイス**: PC、モバイル、タブレットの割合
- **参照元**: どこから来たか（検索、SNS、直接）

## 🎯 AdSense審査のための目標数値

### 最初の1ヶ月
- 日間アクティブユーザー: 20-30人
- 週間アクティブユーザー: 100-150人
- 月間ページビュー: 1,000PV

### 2ヶ月目
- 日間アクティブユーザー: 50-70人
- 週間アクティブユーザー: 300-400人
- 月間ページビュー: 2,000-3,000PV

### AdSense申請時期
- 安定して日間50人以上のユーザー
- 月間2,000PV以上
- 平均セッション時間1分以上
